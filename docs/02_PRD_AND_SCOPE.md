# 02 产品需求与范围

## 定位与参赛主张

HSK Pilot 是一个允许用户用自然语言设定交易边界、由 AI 在边界内自主选择并执行交易、能够逐笔回放证据的 HSKSwap 交易助手。

主张：“Approve the boundaries once. Inspect every decision and every fill.”
价值在于用户能说清规则、系统按规则行动、事后能核对结果。不能宣称经过审计、保本、稳定获利或能防止所有市场操纵。

Track 1 的实际要求见 docs/01 的官方链接。完整性、技术成熟度和创新性是可观察方向；本文件的优先级是内部判断，不是官方权重。

## 用户与工作流

主用户是愿意用自有小额资本验证 AI 执行能力的 HSKChain 钱包 owner。评委默认进入不连接钱包的只读 Demo，能检查真实 session 的政策、交易、P&L 和证据。

1. 浏览真实行情、池、来源、时效、保护模式和未启用能力。
2. 输入“保持约 20% WHSK，单次买入最多 1 USDT，整个会话累计最多买入 3 USDT，至少间隔五分钟；达到预设回撤时停止买入并尝试减仓”。
3. 显示结构化计划、原生数量、仓位边界、滑点、累计毛买入、退出安排、有效期、两签名角色和 mode。示例数值仅为设计样例，实际金额由 owner 批准。
4. owner 签署链上 session；worker 按新鲜链上快照计算偏离，策略 LLM 在允许候选中选择 HOLD 或有界 REBALANCE。
5. risk 独立重查报价和政策，签署相同 intent；协调器自动执行，不要求 owner 每笔确认。
6. 查看实际收到量、失败成本、持仓与净盈亏；自然语言修改政策生成差异卡，由 owner 确认生效。
7. owner 随时暂停/提款；回撤触发器先持久进入 REDUCE_ONLY，再尝试按允许条件减仓。无法成交时明示原因。

## 唯一 P0 策略：有界目标权重再平衡

只支持 WHSK/USDT 的现货单池、exact-input 交易。以偏离目标的带宽为交易触发，AI 决定 HOLD 或在候选范围内交易。初始建仓、市场导致偏离、owner 改目标都是合法触发；不需要伪造套利。

目标不是证明 alpha。盈利观察与执行质量分别评估。对比“持有不动”和“固定规则再平衡”；AI 没有优于基线时，材料如实披露，不将安全性指标偷换为收益提升。

## P0 验收故事

| ID | 需求 | 可验证结果 |
|---|---|---|
| US-01 | 不连钱包查看 Demo | 看到真实链、账户、保护模式、时间、部署及证据；所有 mutation 禁用 |
| US-02 | 自然语言设计划 | 生成 schema 合法差异；不确定参数保持原值/要求有意义澄清，不擅自加大风险 |
| US-03 | 一次授权后自主运行 | 会话内至少一笔由事件触发的交易无需 owner 再点执行 |
| US-04 | 没机会时 HOLD | 显示具体阻塞或策略理由，未广播且模型/RPC费用计入观察 |
| US-05 | 政策改动即时撤销旧意图 | version 增加，旧签名重放被链上拒绝 |
| US-06 | 两类授权都必需 | 缺 strategy 或 risk 任一签名均不能执行 |
| US-07 | 限额不可被循环恢复 | 买→卖→再买仍消耗原始累计毛买入预算 |
| US-08 | 风险退出 | REDUCE_ONLY 禁止增持，独立退出额度可用，不受普通买入额度耗尽影响 |
| US-09 | 外部服务挂掉仍可控制 | RPC恢复后owner可直接暂停/提款；Oracle/EAS/LLM挂掉不成为这两者的前置条件 |
| US-10 | 盈亏可信 | 充值/提现不算盈利，外部gas单列，负值和估值缺失正确呈现 |
| US-11 | 重启不重单 | 未知交易状态先对账同一tx/nonce，不能自动新发相同订单 |
| US-12 | 审查者独立回放 | 导出证据验证hash、链ID、政策版本、收款账户及余额变动 |

## 优先级与删减

P0：只读链上预检、固定账户护栏、真实自主闭环、自然语言政策差异、DEX估值P&L、事件证据、浏览器验收、提交材料。

P1：新鲜独立Oracle增强、EAS异步锚定、长时间观察、图形化会话回放、第二语言完善。只有 P0 已通过且时间允许才做。

删除：同时做套利/网格/动量/LP；五资产扫描；跨链；EIP-7702；HSP付款；智能合约升级；公共存款；代币发行；收费和多用户SaaS；任意AI生成交易 calldata；每四秒一次LLM；链上存储完整聊天和内部推理。

## 工程与体验目标

关键事实都带 block/time/source；行情超过设定时效显示 stale 而非继续绿灯。提交前让评委在 90 秒内完成“规则→成交→政策改变→拒绝/退出”的理解，三分钟版本用于完整演示，实际时长按官方要求调整。

初版英文 UI 和英文提交，中文输入与说明同时支持。首页主视图展示一条活跃任务、一次实际决策和交易结果，避免满屏价格指标与无证据的“Agent思考动画”。

## 商业化边界

未来可验证方向是策略执行审计、个人限额账户和开发者嵌入组件。现阶段没有用户付费、市场规模或交易edge的实证，不用虚构 ARR、用户数或回报率。赛后通过5–10名真实用户访谈、复用意愿及受控试用决定商业路径；这些是拟议研究，不是已完成工作。
